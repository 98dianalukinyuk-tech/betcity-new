# BetCity Pokerroomgids Nederland — Riverline Edition

Onafhankelijke Nederlandstalige bezoekersgids voor fysieke pokeractiviteiten op locatie. Deze website is niet de officiële website van BetCity, gebruikt geen officieel merklogo en mag niet als officiële locatie of exploitant worden gepubliceerd.

## Lokaal starten

Open `index.html` rechtstreeks of start vanuit deze map:

```bash
python3 -m http.server 8080
```

## Voor publicatie

1. Controleer de wettelijke bevoegdheid van de exploitant om fysieke pokeractiviteiten aan te bieden.
2. Vervang alle `{{VERIFIED_*}}`-waarden in `script.js`, canonicals en sitemap door aantoonbaar correcte gegevens.
3. Vervang alle illustratieve foto’s door eigen of aantoonbaar gelicentieerd beeld van de geverifieerde locatie.
4. Verwijder `noindex,nofollow` en `Disallow: /` pas na juridische, inhoudelijke en technische controle.
5. Koppel formulieren uitsluitend aan een veilig, geverifieerd contactkanaal.

Niet-bevestigde blokken blijven automatisch verborgen. De site biedt geen online poker, stortingen, spelersaccount, wallet of deelname via een videospeler.
